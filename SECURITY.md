# Security Policy

## Supported code

Security fixes target the current `main` branch of STORVIA Starter Kit.

## Reporting a vulnerability

Please do **not** publish exploitable vulnerability details in a public issue. Use GitHub private vulnerability reporting / Security Advisories when available, or contact the repository owner privately before disclosure.

Include enough information to reproduce and assess the issue without including real credentials, production data, or private user files.

## Deployment responsibility

A secure deployment must provide its own secrets, HTTPS configuration, database credentials, trusted proxy/host configuration, and filesystem permissions. Example environment files are templates and contain no production secrets.
